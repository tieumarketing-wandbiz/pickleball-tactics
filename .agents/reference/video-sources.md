# Video sources for pose-extraction motion reference (pickleball, tennis fallback)

Internal motion reference only, for a non-commercial 3D animation demo. Links only; no video was downloaded.

## Status and verification

- **Links:** taken from WebSearch results restricted to youtube.com. Each row was checked with YouTube's oEmbed endpoint, which confirms the video exists and returns its title and channel. Rows that failed the check are listed under "Excluded" below.
- **Not verified for any row:** timestamps, camera angle, slow-motion factor, resolution (720p+), and stroke repetition count. I did not watch footage, and the YouTube page fetch returned no description, chapter list, duration, or quality information.
- **"per title":** the camera angle comes only from the video title, not from the footage.
- **One partial exception:** O7LFGzcM5F0 shows chapter start times in a search-result excerpt of its description (0:00, 4:58, 9:18, 10:35, 13:20, 17:26, 18:40). These mark where each player begins, not stroke ranges, so stroke ranges there are still not verified.
- **Attribution notes:** where a search excerpt named a different instructor or channel than oEmbed does, the oEmbed channel is used. The Pickleball Pirates channel carries the Joey Gmuer (PPR-certified) lessons in the search excerpts.

**Checklist before using any clip:** open the link, check the first 5 seconds for a static camera, side or about 45-degree angle, and full body in frame. Scrub for repeated strokes, check the description or chapters for timestamps, and confirm 720p+ in the player's quality menu.
